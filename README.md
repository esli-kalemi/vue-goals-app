# My Personal Goals

A responsive goal-tracking web application built with Vue.js.

## Features

- Add personal goals
- Set goal duration
- Set goal priority
- Calculate expected finish dates
- Edit goals
- Mark goals as completed
- View completed goals
- View overdue goals
- Filter goals by priority
- Goal statistics
- Form validation
- Empty states
- Dark/light mode
- Responsive mobile design
- Accessibility improvements

## Technologies

- HTML
- CSS
- JavaScript
- Vue.js

## Current version

Frontend-only application using browser storage.

## Future plans

- Node.js backend
- REST API
